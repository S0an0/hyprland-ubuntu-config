ШПАРГАЛКА ПО HYPRLAND
=====================

Super — клавиша Windows.
Буквенные сочетания работают в любой раскладке: указана английская
буква на физической клавише, а через косую черту — русская.

ПРОГРАММЫ
---------
Super + Enter             Терминал
Super + Space             Меню приложений
Super + Tab               Переключатель открытых окон
Super + R / К             Запуск команды
Super + E / У             Файловый менеджер
Super + B / И             Google Chrome и страница Google
Super + A / Ф             Визуализатор музыки Cava
Super + T / Е             Выбор цветовой темы
Super + X / Ч             История буфера обмена
Super + W / Ц             Следующие обои

ОКНА
----
Super + Q / Й             Закрыть активное окно
Super + F / А             Полноэкранный режим
Super + V / М             Оконный / плавающий режим
Super + P / З             Псевдотайлинг
Super + стрелки           Перейти к соседнему окну
Super + Shift + стрелки   Передвинуть активное окно
Super + ЛКМ и движение    Перетащить окно
Super + ПКМ и движение    Изменить размер окна

РАБОЧИЕ СТОЛЫ
-------------
Super + 1…9, 0            Перейти на рабочий стол 1…10
Super + Shift + 1…9, 0    Перенести окно на рабочий стол 1…10
Super + колёсико мыши     Предыдущий / следующий рабочий стол
Жест тремя пальцами       Переключить рабочий стол
Super + S / Ы             Показать / скрыть специальный стол
Super + Shift + S / Ы     Перенести окно на специальный стол

СИСТЕМА
-------
Super + L / Д             Заблокировать экран
Super + Shift + Q / Й     Меню выключения и выхода
Alt + Shift               Русская / английская раскладка

СНИМКИ ЭКРАНА
-------------
Print Screen              Выбрать область
Super + Print Screen      Снять весь экран

КЛАВИШИ НОУТБУКА
-----------------
Громкость +/-             Изменить громкость
Отключение звука          Включить / выключить звук
Отключение микрофона      Включить / выключить микрофон
Яркость +/-               Изменить яркость экрана
Play / Pause              Воспроизведение / пауза
Next / Previous           Следующий / предыдущий трек
